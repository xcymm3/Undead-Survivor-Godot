# Undead Survivor · Godot

当前源码仅保留**水晶防线**：穿过吊桥的十波连续尸潮会攻击玩家或水晶。首页可直接选择难度，进入单人增量防守；联机功能暂时关闭，无需选择地图。

[下载 Windows 单文件 EXE](https://github.com/xcymm3/Undead-Survivor-Godot/releases/latest)。已发布版本可能早于当前分支；游戏与 Steam 依赖内置，无需另下 DLL。

## 玩法与操作

保护拥有 1500 耐久的水晶，共十波进攻，第十波清除舞王及全部剩余敌人后通关；水晶被摧毁或玩家倒下则失败。对岸刷新场地为96×96米，僵尸只在以吊桥起点为圆心、半径32米的禁刷圆外，且被树林或岩石遮住的位置出现，再走向吊桥和缓坡。战前准备完成后在警报器上长按 E 开始进攻；每波投放完立即自动接下一波，未击杀的僵尸继续进攻。水晶不在波间恢复。

| 操作 | 按键 |
| --- | --- |
| 移动 / 转向 | WASD / 鼠标 |
| 疾跑 | 按住 Shift，移速 ×1.6，无耐力条 |
| 跳跃 / 蹲下 | 空格 / Ctrl |
| 攻击 / 推搡 / 切换开镜 | 左键 / 右键 / 中键 |
| 换弹 | R，空仓有备弹时自动换弹 |
| 步枪 / 左轮 / 消防斧 | 1 / 2 / 3 |
| 手雷 | 4 |
| 靠近水晶后方商店打开整备界面 | E |
| 开始第一波 | 战前准备或暂停菜单中的“开始进攻”按钮 |
| 靠近已建造的炮塔 / 栅栏门升级 | E（仅战前） |
| 暂停 / 静音 / 全屏 | Esc / M / F11 |

击杀掉落自动飞向玩家的金币，每次清完一波获得1颗钻石。商店可永久升级三种武器伤害、手雷容量、制造左右炮塔和栅栏，以及强壮、精准、迅捷、补给天赋。金币、钻石、升级和建筑保存到用户目录，死亡后保留。第一波开始后本局商店关闭，重开才能再次购买。

步枪和左轮都是有限备弹，清波后分别补充2个备弹夹（步枪60发、左轮12发），可以超出上限；重新开始一局恢复全部弹药。手雷初始1枚、容量最多5枚，每波开始补满；已购地雷和玩家生命每波开始恢复；炮塔、栅栏保留战斗损伤，毁坏后本局不复活。已建造的炮塔和两道栅栏需在战前靠近并瞄准后长按 E 升级，首次20金币，属性乘1.1且后续价格翻倍；三枚地雷每枚100金币永久购买，无升级，旧存档保留原地雷所有权。没有强壮天赋时不自动回血；学习后脱战5秒开始恢复。推搡保留换弹进度，第三次连续推搡后冷却3.5秒。开波前可以射击与推搡。

首页支持三个独立存档，选择后从第一波重新整备；旧永久进度沿用存档1，新存档从零开始。勾选“无限金币”后进入游戏将当前存档金币设为10亿，供测试使用。

舞王拥有橄榄球僵尸10倍生命、2.1米/秒移速，每10秒停下播放3秒迪斯科音乐并跳舞，然后召唤普通类25积分、特殊类25积分的僵尸（不超过预算），召唤单位从附近地面钻出。地图使用月光、夜雾与原有路灯。

价格、天赋和存档规则见 [增量玩法](docs/INCREMENTAL.md)。

## 开发与验证

本项目是独立 Godot 4.5.2 原生工程，运行时不依赖相邻项目、React、Three.js 或浏览器。

- `npm run verify`：版本、无窗口资源导入、原生组件、增量进度/存档与十波战役基础检查。
- `./tools/validate-headless.ps1 -Mode Campaign`：连续接波、独立存档、建筑交互、舞王、钱币动画与通关专项。
- `./tools/validate-headless.ps1 -Mode Defense`：水晶规则专项。
- `./tools/validate-headless.ps1 -Mode DefenseSpawns`：扩大后的对岸随机刷新、圆形禁刷区、出生视线遮挡与路线专项。
- `npm run verify:full`：用户明确要求时运行全量技术检查。
- 正式 EXE 发布由 GitHub Actions 执行 `npm run verify:release`，完成全量技术门禁、导出、成品无窗口冒烟和打包。

本机自动检查必须真正 headless，不打开游戏窗口或干扰桌面。基础通过不等于全量、视觉、实际音效或真人体验验收通过。

设计与验证细节：[地图](docs/MAPS.md)、[增量玩法与商店](docs/INCREMENTAL.md)、[近身战斗](docs/CLOSE_COMBAT.md)、[武器音效](docs/WEAPON_AUDIO.md)、[自动化](docs/AUTOMATION.md)、[按需视觉检查](docs/VISUAL_QA.md)。

全部枪械使用各自的开火声音，消防斧与喷火枪也有独立音效。枪械和炮塔不显示子弹轨迹，包括霰弹枪的每颗弹丸；开火时保留短促、较小的枪口闪光，弹壳和命中效果仍显示。

## 资源与许可

六款枪械及人物资源来自 Quaternius CC0 素材；地图、僵尸、程序化武器和合成音频来自原项目及本工程。许可见 `assets/THIRD-PARTY-NOTICES.txt`、`assets/models/WEAPON-SOURCES.md` 和人物目录许可。资源转换工具仅用于开发，不修改相邻项目。

整备采用场景内八个装备/天赋展台及现场施工点，不打开商店或建筑弹窗。靠近并瞄准显示精简的无边框信息，长按 E 完成一次操作；警报器是唯一开战交互，开战后展台关闭防护罩。
