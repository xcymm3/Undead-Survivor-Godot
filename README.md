# Undead Survivor · Godot

当前源码仅保留**水晶防线**：穿过吊桥的十波连续尸潮会攻击玩家或水晶。首页可直接选择难度，进入单人增量防守；首页“多人合作”支持最多4人的局域网和Steam房间，无需选择地图。

[下载 Windows 单文件 EXE](https://github.com/xcymm3/Undead-Survivor-Godot/releases/latest)。已发布版本可能早于当前分支；游戏与 Steam 依赖内置，无需另下 DLL。

## 玩法与操作

保护拥有 3000 耐久的水晶，共十波进攻，第十波击败舞王后自动清除全部剩余敌人并通关；水晶被摧毁或玩家倒下则失败。对岸刷新场地为96×96米，僵尸只在以吊桥起点为圆心、半径32米的禁刷圆外，且被树林或岩石遮住的位置出现，再走向吊桥和缓坡。战前准备完成后在警报器上长按 E 开始进攻；每波投放完等待10秒后自动接下一波，未击杀的僵尸继续进攻。水晶不在波间恢复。

| 操作 | 按键 |
| --- | --- |
| 移动 / 转向 | WASD / 鼠标 |
| 疾跑 | 按住 Shift，移速 ×1.6，无耐力条 |
| 跳跃 / 蹲下 | 空格 / Ctrl |
| 攻击 / 推搡 / 切换开镜 | 左键 / 右键 / 中键 |
| 换弹 | R，空仓有备弹时自动换弹 |
| 步枪 / 手枪 / 消防斧 | 1 / 2 / 3 |
| 手雷 | 4 |
| 靠近并瞄准展台 / 建筑，升级或制造 | 长按 E（仅战前） |
| 开始第一波 | 瞄准警报器长按 E |
| 靠近已建造的炮塔 / 栅栏门升级 | E（仅战前） |
| 暂停 / 静音 / 全屏 | Esc / M / F11 |

击杀掉落自动飞向玩家的金币，每次清完一波获得1颗钻石。商店可永久升级三种武器伤害、手雷容量、制造左右炮塔和栅栏，以及强壮、精准、迅捷、补给天赋。金币、钻石、升级和建筑保存到用户目录，死亡后保留。第一波开始后本局商店关闭，重开才能再次购买。

步枪和手枪都是有限备弹，初始备弹为当前弹匣容量×6，第2波起每波开始分别补充2个当前容量的备弹匣（未升级时步枪60发、手枪30发），第一波不补、清波不补，可以超出上限；重新开始一局恢复全部弹药。手雷初始1枚、容量最多5枚，开战后每15秒补充1枚至上限；地雷与玩家生命不在波间恢复；炮塔、栅栏保留战斗损伤，毁坏后本局不复活。已建造的炮塔和两道栅栏需在战前靠近并瞄准后长按 E 升级，首次50金币，炮塔伤害与栅栏最大生命每级乘1.25，采用固定升级价格表；三枚地雷每枚100金币永久购买，无升级，旧存档保留原地雷所有权。没有强壮天赋时不自动回血；学习后连续5秒未受伤开始恢复，期间允许攻击。推搡保留换弹进度，第三次连续推搡后冷却3.5秒。开波前可以射击与推搡。

步枪和手枪伤害升级依次为+35%/+33%/+30%/+28%/+26%/+24%/+22%/+20%/+17%/+15%，逐级复利；消防斧仍每级+20%；弹匣每级步枪+5发、手枪+3发，上限10次（80/45发）。本能每级伤害+10%，贪婪每级金币+20%；补给提升初始备弹匣数量，1～5级为8/10/12/14/16，按当前容量计算。蹲伏腰射散布缩小30%。

首页支持三个独立存档，选择后从第一波重新整备；旧永久进度沿用存档1，新存档从零开始。勾选“无限金币”后进入游戏将当前存档金币设为10亿、钻石设为10000，供测试使用。

舞王拥有橄榄球僵尸10倍生命、普通僵尸一半的移速（2.3～2.6米/秒），每10秒停下播放3秒迪斯科音乐并跳舞，然后召唤普通类25积分、特殊类25积分的僵尸（不超过预算），召唤单位从附近地面钻出。地图使用月光、夜雾与原有路灯。

普通类与特殊类各固定使用50%积分预算，互不挪用；前两波特殊池为空，只刷普通半池。普通、路障和铁桶均消耗1分；单人普通难度前两波分别69只、79只。主页恢复战场背景，按钮整组居中，标题使用灰色金属立体透视；鼠标悬停按钮会放大并播放清脆提示音。

价格、天赋和存档规则见 [增量玩法](docs/INCREMENTAL.md)。

## 开发与验证

本项目是独立 Godot 4.5.2 原生工程，运行时不依赖相邻项目、React、Three.js 或浏览器。

- `npm run verify`：版本、无窗口资源导入、原生组件、增量进度/存档与十波战役基础检查。
- `./tools/validate-headless.ps1 -Mode Campaign`：连续接波、独立存档、建筑交互、舞王、钱币动画与通关专项。
- `./tools/validate-headless.ps1 -Mode Defense`：水晶规则专项。
- `./tools/validate-headless.ps1 -Mode DefenseSpawns`：扩大后的对岸随机刷新、圆形禁刷区、出生视线遮挡与路线专项。
- `npm run verify:full`：用户明确要求时运行全量技术检查。
- 正式 EXE 发布由 GitHub Actions 执行 `npm run verify:release`，完成全量技术门禁、导出、成品无窗口冒烟和打包。

本机自动检查必须真正 headless，不打开游戏窗口或干扰桌面。基础通过不等于全量、视觉、实际音效或真人体验验收通过。

设计与验证细节：[工程与地图说明](docs/PORTING.md)、[增量玩法与商店](docs/INCREMENTAL.md)、[近身战斗](docs/CLOSE_COMBAT.md)、[武器音效](docs/WEAPON_AUDIO.md)、[自动化](docs/AUTOMATION.md)、[按需视觉检查](docs/VISUAL_QA.md)。

全部枪械使用各自的开火声音，消防斧与喷火枪也有独立音效。枪械和炮塔不显示子弹轨迹，包括霰弹枪的每颗弹丸；开火时保留短促、较小的枪口闪光，弹壳和命中效果仍显示。

## 资源与许可

六款枪械及人物资源来自 Quaternius CC0 素材；地图、僵尸、程序化武器和合成音频来自原项目及本工程。许可见 `assets/THIRD-PARTY-NOTICES.txt`、`assets/models/WEAPON-SOURCES.md` 和人物目录许可。资源转换工具仅用于开发，不修改相邻项目。

整备采用场景内八个装备/天赋展台及现场施工点，不打开商店或建筑弹窗。靠近并瞄准显示精简的无边框信息，长按 E 完成一次操作；警报器是唯一开战交互，开战后展台关闭防护罩。

主页固定普通难度。手枪弹匣15发、初始伤害100，旧存档的左轮升级迁移至手枪；消防斧支持右键推搡。整备交互长按E三秒，圆环显示进度，钱币从玩家飞向目标。舞王在第10波启动时立即登场，移速与普通僵尸相同。


## 房主存档合作

首页“多人合作”可创建局域网房间，或通过IP与端口加入；Steam版可创建、搜索大厅、按房间号加入及邀请好友。所有成长跟随房主当前存档，金币和钻石仅归房主；客机使用临时成长，退出后个人存档不变。个人弹药、手雷、大招独立。客机死亡后整局观战且不复活，房主死亡或水晶被毁则全队失败；人数不增加难度。第一波开始前可加入，之后仅原成员可重连，保留原状态。

网络协议与验证边界见[合作说明](docs/COOP.md)。Steam仍使用测试App ID 480，需要GodotSteam运行环境和已登录的Steam；局域网本机验证不能代表Steam双账号跨网络验证。
