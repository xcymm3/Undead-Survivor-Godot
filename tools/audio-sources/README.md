# CC0 source excerpts

These committed PCM16 excerpts are the inputs to tools/build-cc0-audio.py.
index.json records each upstream page, author, CC0 license URL, downloaded archive SHA-256, original member SHA-256, excerpt interval, conversion and excerpt SHA-256.
The excerpts were decoded from WAV/OGG/MP3 with libsndfile, averaged to mono (except music), resampled to 44.1kHz and saved as PCM16. They are not oscillator/noise synthesis.
The Free Firearm Sound Library's Prepared Master Sheet.csv supplied weapon and distance metadata. Plastic snap uses its public HQ preview, not an authenticated original download.
.gdignore prevents Godot importing these development sources. Production audio is under assets/audio; full Chinese mapping and selection rationale is in docs/AUDIO_SOURCES.md.
