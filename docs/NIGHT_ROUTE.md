# 灰松夜路

本关替代旧十五分钟战役的菜单入口。目标是约三分钟抵达安全屋，不设最低通关时间，不靠等待开关延长流程。旧灰松渡口源码保留用于历史规则回归，常规单人和多人选图不再提供旧长关卡。

## 路线与体验

| 路段 | 设计时间预算 | 遭遇与判断 |
| --- | --- | --- |
| 值班室 → 堵车街口 | 35–45 秒 | 初始补给、开门、从车辆与建筑转角之间观察前路；出门保留观察距离 |
| 穿过临街店铺 | 30–45 秒 | 屋顶压低空间，货架遮挡两侧；出口可见绿灯，后方仍有追兵 |
| 店后林缘 → 维修车辆 | 50–60 秒 | 灌木、树干、车辆切断远距离射界；选择从尸群空隙推进，路边可换枪 |
| 暖灯入口 → 关门 | 25–35 秒 | 避开边缘尸群，进屋集合，清掉真正进入屋内的敌人并按 E 关门 |

以上是设计预算，不是验收实测值。内部受限角色知道路线、可以读敌人状态；采用 120 度/秒转向、0.7 度瞄准误差、0.25 秒反应和转角观察停顿。约三分钟目标对应内部 120–240 秒初步校准区间；真人首玩和趣味性单独待验收，不用该区间冒充精确三分钟。

## 守路者与增援

- 单人开局预置 200 只：街口 46、店铺及两侧 44、林缘 68、终点前 42。多人按 1 / 1.2 / 1.4 / 1.6 倍配置，保持有限总量。
- 主路径中心留空，优先使用被实体掩体遮住的落点；所有落点参与同一导航与物理碰撞检查。边缘敌人也可寻路进入主线，不把无法接近的背景人偶算作敌人。
- 待机时手臂下垂、身体前倾、呼吸晃动并缓慢转头；四分之一的守路者在原位附近短距离踱步。GPU 实例与 CPU 命中共用根姿态，手臂姿态在两侧采用相同变换。
- 7 米内目视唤醒；附近枪声在无遮挡 12 米、隔墙 4 米内唤醒。受伤直接唤醒，不全图共享玩家位置。被唤醒后持续追击。
- 普通追击速度 3.8–4.2，玩家站立速度 4.2。部分敌人选择玩家左右可达位置，增加局部分离；窄门仍允许自然汇流。近战不能隔实体墙或车辆造成伤害。
- 无护甲普通僵尸中弹会短暂踉跄 0.18 秒，0.8 秒内不会再次触发，给予射击反馈和脱身机会；不会增加血量或无限定身。
- 林缘事件一批 12 只；65 秒和 125 秒各一批 10 只，多人同倍率。单人活跃增援投放上限 24（包含已醒守路者），多人 36 / 46 / 56。上限只延后增援，不让预置敌人忽然停止追击。
- 增援落点必须远离玩家、被实体遮挡、与道路连通；受阻保留剩余名单，没有过期丢弃，也没有无限刷新。
- 没有清场目标。安全屋门只检查队伍集合、屋内敌人与门口占用。

## 画面与资源

冷色低环境光、距离雾、带阴影手电、零散绿灯与安全屋暖灯共同组织明暗。实体车辆、树干、灌木、建筑和货架共享导航障碍；树冠是高处视觉遮挡。低亮度不作为允许当面刷怪的理由。

沿用三大武器槽、两小道具槽和每人一枚手雷、一个医疗包。开局与店铺提供 B 级枪械，林缘车辆提供 A 级枪械；通过换枪获取弹药。消防斧保持 100 伤害，可一击杀死普通僵尸。

## 验收边界

`tools/validate-night.gd` 检查预置数量、落点、主线路径与所有藏身点的可达性、门交互、待机姿态、有限增援保留，并记录两个固定种子的真实输入遍历及死亡诊断。失败样本不重抽种子，不删记录。

`npm run verify` 执行当前夜路测试、双人整关 ENet 和独立 headless Chromium 软件截图。其他地图及其专属测试已删除；后续仅检验夜路单人与双人，共用装备与导航规则在夜路上验证。软件图必须逐张审查；原生 GPU、连续运动观感、真人首玩和 Steam 双账号均不能由这些检查替代。
