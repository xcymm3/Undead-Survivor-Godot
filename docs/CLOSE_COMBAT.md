# 近身战斗（v1.11.0）

- 右键：持枪或消防斧时推击；医疗包仍给队友治疗。中键按一下开镜，再按一下退出，暂停/失焦会清除开镜状态。
- 推击由单人/房主 simulation 权威处理。距离上限 4.16 米、前方 160 度，无直接伤害；必须与目标同高度且没有实体墙阻隔。
- 普通敌人击退 2.8 米并硬直 3.12 秒，巨人击退 0.9 米并硬直 0.91 秒。位移分段检查地形；不能把敌人推穿墙或跨越不可通行地形。持盾和橄榄球僵尸在所有状态下免疫推击的击退与眩晕。
- 每次推击最短间隔 0.65 秒；相邻推击不超过 3 秒则累计，第 3 次完成后进入 3.5 秒冷却。准星上方橙色加载环显示恢复进度，结束消失。推击会中断换弹，不赠送未装填弹药；动作期间不能射击。受击、冷却和击退均随合作快照同步，右键使用可靠计数恢复输入边沿。
- 每个敌人生成时抽取固定基础速度 4.6～5.2 米/秒，独立种子不消耗刷怪种类的随机流。普通、路锥、水桶和橄榄球直接使用该范围；小鬼为原1.08倍率再提高20%，即基础速度的1.296倍（5.96～6.74）；盾牌0.78倍，巨人0.68倍，爬行者0.85倍；狂暴者常态使用基础速度、狂暴后固定7.2；橄榄球冲锋固定12。涉水追击仍乘0.7，冲锋入水取消。
- 接近玩家时按敌人稳定索引分配不同方位的接敌位置，远处绕向外圈、近处收至攻击圈；候选点必须能连接玩家，实体狭道仍需依次通行。局部分离增强，不能承诺任何狭窄地形都绝不排队。
- 跑步步频随实际位移推进，停止不原地滑步；腿部跨幅、抬脚、摆臂和前倾增强。每只僵尸使用 6 根原生骨骼，同侧袖口与手、裤腿与鞋共享骨骼，肩部/髋部为转轴。渲染和 CPU 命中检测直接复用同一套姿态；不再依赖旧的实例顶点动画。
- 普通僵尸前摇0.5秒、攻击周期1.3秒。伤害帧前按实际追击速度继续推进，朝锁定目标的转向上限为每秒120度；伤害帧后停止推进并完成收势。挥击仍重新检查距离、朝向、墙体与目标高度：直线后退会被速度更快的敌人追上，横向脱离攻击方向仍会挥空。前摇推进使用下半身步态与上半身挥击混合，渲染和CPU命中姿态继续共用同一状态。空间声音分为蓄力低吼、命中、挥空，以及推击命中/挥空。音频为本项目脚本生成的原创合成 WAV，不采用外部录音。

## 验收边界

功能检查覆盖推击扇区与 4.16 米边界、冷却、打断、持盾/橄榄球全状态免疫、速度范围、攻击挥空/命中、输入与联机计数、声音资源。浏览器用真实右键和中键验证加载环及恢复；软件图库检查奔跑和攻击姿态。原生 GPU、实际音频听感、多人主观难度和趣味性仍需真人验收。完整试玩失败样本保留在 artifacts，不把功能通过称为平衡达标。
