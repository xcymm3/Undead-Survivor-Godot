# 近身战斗（v1.11.0）

- 右键：持枪或消防斧时推击；医疗包仍给队友治疗。中键按一下开镜，再按一下退出，暂停/失焦会清除开镜状态。
- 推击由单人/房主 simulation 权威处理。半径 2 米、前方 140 度，无直接伤害；必须与目标同高度且没有实体墙阻隔。
- 普通敌人击退约 1.30 米并硬直 1 秒，重型（巨人、盾牌、橄榄球）约 0.36 米、0.35 秒。位移分段检查地形；不能把敌人推穿墙或跨越不可通行地形。橄榄球冲锋准备及冲锋阶段免疫普通推击。
- 每次推击最短间隔 0.65 秒；相邻推击不超过 3 秒则累计，第 3 次完成后进入 3.5 秒冷却。准星上方橙色加载环显示恢复进度，结束消失。推击会中断换弹，不赠送未装填弹药；动作期间不能射击。受击、冷却和击退均随合作快照同步，右键使用可靠计数恢复输入边沿。
- 每个敌人生成时抽取固定基础速度 4.6～5.2 米/秒，独立种子不消耗刷怪种类的随机流。普通、路锥、水桶高于玩家 4.2 米/秒；小鬼倍率 1.08，盾牌 0.78，巨人 0.68，橄榄球有甲 0.90、无甲 1.0；狂暴者保留速度上限 5.8。涉水仍乘 0.7。
- 接近玩家时按敌人稳定索引分配不同方位的接敌位置，远处绕向外圈、近处收至攻击圈；候选点必须能连接玩家，实体狭道仍需依次通行。局部分离增强，不能承诺任何狭窄地形都绝不排队。
- 跑步步频随实际位移推进，停止不原地滑步；腿部跨幅、抬脚、摆臂和前倾增强。每只僵尸使用 6 根原生骨骼，同侧袖口与手、裤腿与鞋共享骨骼，肩部/髋部为转轴。渲染和 CPU 命中检测直接复用同一套姿态；不再依赖旧的实例顶点动画。
- 普通僵尸前摇 0.5 秒、攻击周期 1.3 秒；敌人攻击有承诺的前摇和收势：挥击时重新检查距离、朝向、墙体与目标高度，离开范围会挥空。空间声音分为蓄力低吼、命中、挥空，以及推击命中/挥空。音频为本项目脚本生成的原创合成 WAV，不采用外部录音。

## 验收边界

功能检查覆盖推击扇区、冷却、打断、冲锋免疫、速度范围、攻击挥空/命中、输入与联机计数、声音资源。浏览器用真实右键和中键验证加载环及恢复；软件图库检查奔跑和攻击姿态。原生 GPU、实际音频听感、多人主观难度和趣味性仍需真人验收。完整试玩失败样本保留在 artifacts，不把功能通过称为平衡达标。
