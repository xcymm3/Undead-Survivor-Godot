# 左轮第一人称动作样板

仅左轮启用专用双手和第一人称模型。其他枪械继续不显示第一人称手臂；第三人称与地面拾取仍使用原左轮资源。参考用户提供的低多边形持枪画面制作原创几何，不包含截图游戏的模型或动画资源。

## 动作

- 持枪：双手环抱握把，分节手指、拇指、手腕与袖口，轻微呼吸。
- 行走：根据实际水平位移累积步伐，平滑进入、停止；转向有小幅滞后，开镜时明显衰减。
- 开镜：使用原输入状态与平滑过渡，后照门、前准星保持可见。
- 射击：短促抬枪与回落，击锤、扳机/食指和转轮配合，枪口火焰跟随实际模型枪口。
- 换弹：拇指接近卡笋，转轮向左打开，推退壳杆、弹壳离开、左手取快速装填器、对准弹巢插入、取走装填器、合拢转轮并重新握持。
- 切换：收枪和拔枪；换弹中断后短暂收回手部与零件，切到其他武器立即隐藏整套左轮双手，重新切回不会残留弹壳或装填器。死亡不保留活动双手。

动作使用分阶段曲线和节点关节，属于程序制作的关键姿态动画。保留原有 6 发容量、150 伤害、1.6 秒换弹及射击间隔，不通过动画提前补弹。1.6 秒动作采用快速装填器的紧凑节奏；弹药只由原权威模拟在换弹完成时改变。
