# 联机须知与回合重生

首次进入多人界面自动打开须知，用户必须将原生滚动条拖到底部才能确认。确认状态保存在全局设置 coop_notice_seen，与存档槽位独立；取消或在须知中按 Esc 返回主菜单，不记录确认。右上角按钮可随时重开，重新阅读也需滚到底。

客机死亡后保持观战，实际清完客机阵亡时所在的一轮防守并发放波次奖励时，由房主在出生点复活仍连接的客机；新波提前出怪并不等同于旧波完成，不会提前复活。房主死亡或水晶摧毁结束本次防守。

失败先展示第一人称倒下或原有水晶破碎（水晶导致失败时取景到水晶，保证在商店中的玩家也能看到破碎）；胜利保留舞王倒下。之后淡入黑幕、显示“今晚，无人生还...”或“太阳升起，你活下来了...”，在全黑时重建新一轮，再从出生点淡出。没有胜负结算弹窗，经济奖励仍由原有权威流程落盘，客机不写入个人成长。

多人各端播完黑幕文字后发送 ending_ready。房主等待所有仍连接的队员完成，再执行原有全员地图加载握手；握手期间客机保持黑屏，禁止误切单人。该消息受匹配 nonce 和成员身份校验，协议更新为 undead-survivor-godot-27，双方须同版本。断开连接的成员不阻塞重开；只剩房主时在黑幕下回到单人新一轮。

老板头顶叹号采用更大的金色字形、深色描边、穿透深度显示和呼吸/上下浮动，只在原有待对话阶段显示。

基础检查覆盖须知门禁、自动遮黑重生、经济奖励与 ENet 双进程失败/胜利重开及清波复活；Steam双账号、原生GPU和真人体验不包含在这些自动检查内。按需GIF在 GitHub Actions 隔离 Web 软件渲染环境生成，不启动用户桌面图形进程。
