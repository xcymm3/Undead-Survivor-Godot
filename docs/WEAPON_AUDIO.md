# 战斗音效

2026-10-16：武器、换弹、死亡、刀动作、脚步、推搡、撞击、护甲与开大音乐改为现成CC0素材，共54条。完整来源、逐文件选择理由、型号替代说明与换弹动作标记见 [音效来源记录](AUDIO_SOURCES.md)。本记录覆盖此前“所有武器均由程序合成”的说明。

- 开火：8种枪械分别取实录库的独立单发；消防斧使用破风与衣物层，喷火枪使用已有燃烧素材。炮塔仍复用步枪声。本地与空间音频池保留24／32声部。
- 换弹：9种可换弹武器使用独立、与动作等长的录音轨道，按弹匣、逐发装填、弹巢和枪机阶段定位。专用单声部播放器从当前换弹进度开始；取消、切枪、暂停、失焦和死亡停止，恢复按当前时间寻址。音高不随机变化。斧头无换弹声。
- 长刀：拔刀、收刀与3种挥刀独立，按拔收刀与挥砍时钟播放；新动作替换旧动作声。没有恢复武器切换表演动作或切换音效。
- 死亡：6条短声，避免紧邻重复；每80毫秒最多接入3个死亡声起音。
- 脚步：木桥、石面坡道／高地、草地各3条；仍限制附近敌人和每帧播放数量。
- 护甲：路障使用塑料，铁桶使用薄铁皮，盾牌使用厚金属，橄榄球护具／巨人皮盔使用软质与皮革；命中、破坏分开。
- 开大：选取nene《Short Theme [Rock/Metal]》38–48秒段，结束前淡出；普通音乐在技能期间压低12dB，结束恢复。其他未列出的音乐、购买和提示音不在本次替换范围。

构建：`python tools/build-cc0-audio.py`。只读检查：`python tools/build-cc0-audio.py --check`，已纳入 `npm run verify`。历史合成工具拒绝覆盖这些录音。

无窗口检查只验证来源、资源、事件和时间，不代表实际听感通过；未在用户桌面播放音频。
