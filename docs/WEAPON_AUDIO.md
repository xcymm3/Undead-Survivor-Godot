# 武器音效

所有武器按 `assets/data/rules.json` 的武器 ID 选择独立音效，资源名为 `assets/audio/weapon-<id>.wav`。本地玩家使用普通音频池，其他角色与炮塔使用空间音频池；炮塔采用步枪音效。消防斧与喷火枪也有各自的声音。

| 武器 | 声音设计 |
| --- | --- |
| 步枪 | 干脆爆音、中等低频、短枪机声 |
| P90 | 更短、更亮的爆音，低频较少，快速机构声 |
| 半自动手枪 | 紧凑枪声与套筒回位声 |
| 左轮手枪 | 更厚的低频、弹巢间隙喷气声与较长尾音 |
| 泵动霰弹枪 | 宽而低沉的爆音，随后分两段泵动拉栓声 |
| 栓动狙击枪 | 尖锐初始爆音、较长远处回声、栓动机构声 |
| 消防斧 | 随挥动加速的破风声与握柄摩擦声，空挥不附加命中撞击 |
| 喷火枪 | 平缓起落的加压气流与低频燃烧声，连续射击时相邻片段重叠 |
| 自动霰弹枪 | 较紧凑的低频爆音和快速自动循环声 |
| 重机枪 | 低沉的逐发冲击与较粗重的供弹机构声 |

这些是原创程序合成声音，没有使用外部录音。不同声音由不同的噪声频段、瞬态包络、压力脉冲、尾音和机械声组合产生；小范围随机音调只用于减少连续播放时的重复感。

生成命令：`python tools/generate-weapon-audio.py`。只读质量检查：`python tools/generate-weapon-audio.py --check`。脚本固定随机种子，输出单声道 44.1 kHz、16-bit PCM WAV，检查所有武器覆盖、逐字节可复现、波形差异、峰值余量、能量、首尾过渡及直流偏移。

运行时保持 24 个普通音频声部与 32 个空间声部的固定池。`--headless` 或 `--silent` 检查只记录资源、位置与音量路由，不启动音频播放。无窗口检查不能替代真人试听；此次没有在用户桌面播放声音。
