# 消防斧左右劈砍

## 观察来源

- Kubold 官方视频：[FPP Melee Animset - Halberd - UE4](https://www.youtube.com/watch?v=3e4xRsBx_Mw)，154秒，读取日期2026-10-16。
- 通过命令行读取公开视频帧，不打开播放器或桌面窗口。全片每2秒取帧定位动作，再查看12–18秒、30–36秒每秒8帧的连续画面。
- 视频展示的是长柄斧／戟。可观察到侧后回收、双手向前送柄、越过目标后的随挥、较慢的回收，以及不同方向的攻击姿态；它不是消防斧的现成动画。
- 本工程依据上述运动特征独立编排关键姿态和曲线，没有导入或提取Kubold的FBX、骨骼、模型、动画轨道。参考视频与分析帧仅在忽略的开发缓存中，不作为游戏资源分发。

## 本次实现

`scripts/axe_motion.gd`分别编排从右向左、从左向右的两条斜向劈砍。两套轨迹的高度、前送距离、柄倾角和收势不同；反向挥击重新确定斧刃朝向，避免以斧背／尖镐先接触目标。

| 归一化阶段 | 普通斧头时间 | 动作 |
| --- | --- | --- |
| 0–0.22 | 0–0.1232秒 | 从当前显示的姿态回收到对应侧的蓄力位 |
| 0.22–0.46 | 0.1232–0.2576秒 | 向前、斜下加速切入，斧刃越过中线 |
| 0.46–0.66 | 0.2576–0.3696秒 | 穿过命中扇区，向对侧下方继续挥击 |
| 0.66–1 | 0.3696–0.56秒 | 减速随挥，保留对侧收势 |

斧刃位置使用保持单调的三次Hermite插值；柄姿态用四元数插值，再从刃口位置反推握持位置。有效挥砍区间保持0.22–0.66，与现有权威命中扇区共享常量。伤害、距离、0.6秒攻击间隔和0.56秒动画时长保持原值。

连续攻击间的40毫秒空隙保留随挥；下一次攻击从实际显示的姿态起手。停止攻击后先停留80毫秒，再于260毫秒内回到共同待机姿态。切换武器、死亡等中断复位，不添加切换动作。第一人称与队友模型使用同一套轨迹及`axe_direction`。

现有CC0挥斧录音保留，将主瞬态从约0.205秒移到约0.258秒，对齐过中线阶段。独立动作音轨使用`fire_anim`和`shots`定位，固定音高；重复消费射击事件不会双重播放，暂停／切换时停止。命中声仍由实际命中事件触发。

## 验证范围

基础检查包含`tools/validate-axe-motion.gd`：刃口单向穿越、刃面领先、刚体姿态与曲线连续性、前送距离、左右不同姿态、30/60/144Hz连击接续、停止回收、切换中断、首人称／队友实际模型接入、音轨偏移与去重。

检查为真正headless的技术验证；未启动可见游戏、执行原生GPU画面验收或进行真人手感／音效试听。视频帧观察不等同于本次游戏画面已验收。
