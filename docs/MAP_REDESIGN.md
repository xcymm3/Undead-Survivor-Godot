# 入口、修复开波与玩具防线

## 地图动线

- 玩家出生于吊桥远岸入口`(0,-66)`附近，地面高度0，面向吊桥；入口增加蓝色踏板、黄色方向标和提示牌。
- 吊桥范围`z=-62…-28`，随后通过缓坡登上3米高地；水晶位于高地中心`(0,17.3333)`，商店位于其后方。
- 保留桥侧护栏、共享地形、栅栏、敌人出生区域与隐蔽出生规则。实际角色胶囊的无窗口行走检查覆盖出生点至桥面、缓坡和水晶前方。

## 新局与修复

所有新局，包括失败后重进和存档选择后开局，均创建新的破损水晶：当前生命0、修复标记为真、碎片已落地、敌人尚未投放。战前的零血量不触发失败；开战后被击毁仍正常判负。

对准水晶时显示“水晶已破损 / 长按 E 修复 / 修复完成立即开始进攻”。沿用现有长按交互的一秒确认圈；修复免费，不检查金币或钻石。松开、转头、离开有效距离或遮挡会取消未完成的进度。完成后恢复3000生命、启用完整模型与碰撞、立即发出第一波事件，同时关闭展台。持续按住不能重复启动；后续接波不恢复战斗损伤。若角色站在破损水晶内部，恢复碰撞前将其移至底座外，避免卡进实体。

警报拉杆实体、相关交互目标、说明和T启动映射已移除。权威开波仍位于`defense_director.gd`，客户端不能提交水晶生命或完成状态。

## 玩具外观

四类对象共用原生程序几何和塑料材质，不引入额外模型依赖：

| 对象 | 造型 |
| --- | --- |
| 炮塔 | 蓝色拼装底板、黄色凸点、珊瑚色支柱、圆润外壳、旋钮与橙色安全枪口；损坏后外壳松脱，保留跟踪、俯仰、后坐与闪光 |
| 水晶 | 彩色凸点插座、奶油色拼装接缝、青色不透明晶体；破损时保留底座并散落可重新拼装的块件 |
| 地雷 | 蓝色圆盘、珊瑚色外壳、黄色边圈和凸点；待机绿灯慢闪、触发红灯快闪，继续共用手雷引信和爆炸音效 |
| 八个展台 | 彩色积木柜体、奶油色台面、黄色凸点、功能铭牌与玩具柜盖；保留商品、交互距离、关闭状态和碰撞 |

## 验证与截图

`tools/validate-map-redesign.gd`覆盖实际出生朝向和行走、战前零血量安全、免费修复、短按／转头取消、立即开波、重复触发、后续波次不回血、失败后重进，以及四类玩具造型的实际场景接入。

本地只运行真正headless的基础和相关专项检查。截图使用`map_toys`隔离Actions入口，通过Godot Web、无界面Chromium与SwiftShader生成。包含带名称标注的全景、出生视角、修复提示、修复后水晶及三类物件特写；全景和特写有隔离审查补光，玩法光照不变，物件特写隐藏HUD以免遮挡。逐图观察记录保存在`artifacts/visual-review.md`，截图不等同于原生Windows GPU或真人体验验收。
