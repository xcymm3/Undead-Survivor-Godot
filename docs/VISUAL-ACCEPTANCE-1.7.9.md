- 队友的武器原先固定在头部附近；改为跟随右手骨骼握点，长枪双手握持，并扩大第三人称武器显示比例。

- 为第三人称增加枪口火光，并校准喷火器、连喷及重机枪枪口。
- 第三人称装填原先播放弯腰拾取动画；改为保持持枪姿势和副手配合。
- 消防斧的第三人称握柄在挥砍时离手；通过手臂与握点同步修复。

## 重现方式

在明确授权后台视觉检查后运行：

```powershell
node tools/prepare-visual.mjs
node tools/capture-visual.mjs
npm run verify:release
```

视觉准备脚本只在 artifacts/visual-project 中加入固定姿势控制，不将这些控制写入正式游戏。捕获脚本使用独立无窗口 Chromium，完成后关闭自己创建的浏览器和服务。

新增逻辑回归覆盖任意朝向曳光起终点、10 把武器握点及有限枪口坐标。完整测试结果以 artifacts/acceptance.md 和当前提交的 GitHub Actions 为准。

## 尚未覆盖

没有验证原生 GPU 驱动上的画面差异、Steam 跨账号联机，也没有逐帧审查所有移动/跳跃/极端俯仰与武器动作的组合。角色仍使用通用持握骨骼，不包含逐枪手指或弹匣接触的精细动画。此次通过意味着上述受检范围符合要求，不代表游戏没有其他缺陷。
