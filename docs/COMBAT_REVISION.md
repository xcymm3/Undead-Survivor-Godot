# 水晶防线战斗与补给

本文记录旧战斗改版。固定装备、商店、有限备弹、天赋回血及永久进度的现行规则见 [增量玩法](INCREMENTAL.md)。

## 装备

- 四格装备栏：1 武器1、2 武器2、3 固定消防斧、4 手雷；空手雷栏不可切入。两个武器槽允许任意武器并独立保存弹药。
- 军械墙仅提供步枪、自动霰弹枪、喷火枪和狙击枪，替换当前武器槽并补满弹仓与17个备用弹匣。每波实际开始时手雷自动补满至3枚。
- 移除医疗包及治疗操作，保留原有脱战自动回血。半自动手枪第一人称只显示枪械，不显示手臂。
- 手雷投掷读取本帧朝向，原生模型显示飞行和引信阶段，空间音效跟随投掷物。引信 1.5 秒，半径 11 米，最多携带三个，不伤害自己或队友，爆炸受墙体阻挡。
- 泵动霰弹枪有已装入子弹时可中断装填并射击，未完成的装填不会补弹；推搡保留装填进度。

## 敌人与控制

- 非致死枪击产生约 0.22 米小幅位移，受碰撞限制；同一齐射不会叠加，已有更强推搡控制不被覆盖。
- 巨人、半血狂暴者不受枪击位移，橄榄球冲锋时也免疫；玩家推搡可正常击退巨人、持盾、非冲锋橄榄球与狂暴者，但不会造成眩晕。橄榄球蓄力与冲锋时免疫推搡。
- 橄榄球为 3000 本体、6000 护甲；狂暴者 3000 生命、半血狂暴；巨人 4000 本体、2000 全身护甲。
- 积分成本：普通 0.75、路障 2、铁桶与小鬼 4、盾牌 6、狂暴者与巨人 12。特殊敌人从第1波最多使用25%的积分逐步提升至第10波最多50%，其余按普通价格补足；整数只数造成的尾数小于0.75分，不超额消费。爬行僵尸不再自然生成。
- 水晶防守第六、七波各投放玩家人数只橄榄球，第八波及之后每波投放玩家人数的两倍，不消耗普通积分预算。
- 僵尸待机具有轻微摇摆；动作显示与 CPU 命中检测共享姿态。每波开始播放低沉号角。

## 验证边界

`tools/validate-native-components.gd` 覆盖装备、治疗、手雷、弹道、动作、近身战斗与输入。`tools/validate-defense.gd` 覆盖地图碰撞、军械库、波次、积分预算、多人重新按 T 准备、水晶索敌与胜负。资源和规则断言不代表实际音效听感、原生 GPU 画面、Steam 双账号联网或真人平衡已通过。
