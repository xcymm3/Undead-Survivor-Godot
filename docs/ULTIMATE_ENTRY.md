# 首次终极武器选择

新槽位从主菜单开始游戏时，先播放原有九秒开场白，再进入独立的约24×14米展厅。场景位于主战场之外，拥有自己的原生地面、墙体碰撞、玩家胶囊和环境；主地图隐藏，选定前不创建战斗模拟。

- 左区：青紫科技霓虹、服务器、反应环与原生火箭炮模型。
- 中区：蓝色石木古风、月门、屋檐、灯笼与已有长刀模型。
- 右区：猩红哥特尖拱、彩窗、烛台与原生猩红权杖模型。

提示栏沿用“Shift 疾跑”的黄油体、描边、金边底板和顶部位置，显示“选择你的终极武器”。移除左下角移动与新手提示。靠近并注视武器时，在与升级展台相同的左侧详情面板显示武器属性，长刀基础伤害从正式数值读取（200）；离开交互范围隐藏详情。玩家移动并注视展台，靠近后持续长按交互键1秒确认选择，展台显示与升级共用的交互按钮及环形进度；松键、转移视线或离开交互范围会清零。完成反馈仍使用原本的米白边框与金色进度，不再变绿。火箭炮和权杖显示“Demo版不可用”，不能选取。长刀选择成功落盘后淡入黑屏，在完全遮挡时初始化正常武器商店，再淡出黑屏。写盘失败保留展厅并允许重试；首次选择不直接授予原有教学中的大招解锁。

存档版本10增加`ultimate_choice`。已经开始游玩的版本9存档迁移为长刀，保留成长并跳过新展厅；空白旧槽位仍需选择。故事完成与选刀分别记录，中断后不会错误跳过未完成的选择。各槽位独立。

合作房主首次使用新槽位时，先完成个人选刀，再发起全员战场加载握手，避免客机在房主选刀期间加载超时。客机个人存档保持独立。网络协议26要求双方版本一致。

## 检查与录制

`npm run verify`包含`UltimateEntry`真正headless专项回归，检查隔离场景、移动碰撞、禁用武器、保存失败回滚、旧存档迁移与遮黑切场。`NativeSmoke`通过引擎输入走首次进入与选刀流程。

`preparation-visual.yml`的`ultimate_entry`范围在GitHub Actions隔离环境中导出Web，并使用headless Chromium软件渲染录制开场、三展区、不可用提示、长刀确认和商店过渡。浏览器发送真实 WASD、鼠标移动和 E 键事件；逐帧通过正式物理输入路径行走和碰撞，禁止改写玩家位置、视角或直接选刀。录制包括走近左右禁用武器、鼠标观察、回到长刀、长按确认和商店过渡。GIF不是原生GPU、真人鼠标操作或Steam双账号验收。
