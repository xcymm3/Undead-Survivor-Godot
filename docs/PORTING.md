# Godot 工程说明

本仓库是从旧项目移植并继续开发的独立 Godot 4.5.2 工程，运行时不依赖 React、Three.js、Electron 或相邻源码目录。Steam 使用与 Godot 4.5 匹配的 GodotSteam 4.16 模板。

## 当前范围

- 工程只保留 `graypine_defense`：保卫水晶，包含吊桥、缓坡、开阔平台与夜间十波连续防守；战前启动第一波，各波投放完成后等待10秒接波，第十波击败舞王后自动清场并通关。当前按十波名单均分预算、向下取整，余数补成名单内1积分僵尸；橄榄球按积分生成。旧基础曲线从138起，增量按 `max(5, round(31 × 0.92^(波次+1)))` 计算，原波次折扣、人数与难度系数计算完毕后，最终预算除以2并向下取整。完整成本和逐波构成见本文末尾的“按类型均分积分生成”。
- 当前运行提供单人增量玩法，规则见 [增量玩法与存档](INCREMENTAL.md)。多人入口及普通运行中的建房、加入暂时关闭，旧网络模块和模拟接口保留。
- 跳跃保留世界坐标水平速度，空中输入按方向投影限速逐步加速：加速度 4 米/秒²、输入方向速度上限 1.5 米/秒、总水平速度上限 4.2 米/秒。松键和转动视角保留惯性，反向键逐步减速；空中蹲下不缩放已有速度，墙体碰撞移除受阻速度，落地恢复地面移动。该规则借鉴 Source 空中加速思路，参数适配本游戏，不宣称完全复刻 CS:GO。
- 地形、碰撞、寻路、敌人 CPU 命中姿态和 GPU 显示共享同一组原生规则。
- 玩家固定携带步枪、普通手枪、消防斧和手雷；两把枪使用有限弹药，每次清波各增加 2 个备弹夹，可超过上限。军械库改为开波前商店，金币、钻石、装备、建筑和四种天赋永久保存。其他武器资源仅保留供旧动作与命中专项使用。

## 敌人二维移动

出生位置在96×96米的对岸正方形场地连续随机采样，不再使用五个固定刷新点。以吊桥起点为圆心，出生点至少距离32米；桥面、本岸、障碍净空内和无法走到桥口的地点不能生成敌人。77棵树、低矮灌木和22块岩石分布在11组树林中，树干和岩石同步阻挡物理移动与二维寻路，叶片使用独立视线层且不阻挡子弹。出生时检查所有存活玩家眼睛到敌人轮廓的9条射线，涵盖脚、躯干、帽顶和两侧边缘，实际被遮挡才允许生成，不依赖当前镜头朝向。检查轮廓由各类敌人模型部件计算并缓存，避免漏掉路障帽、铁桶和特殊体型；出现可见采样点立即拒绝。树林分三组 MultiMesh 绘制，出生通行用一次连通区域预计算代替逐点 A*。位置随机数独立于战斗和波次组成；保持原有30秒批次、与玩家至少8米距离及出生点间距策略。候选尝试有上限，暂时没有隐蔽出生点时保留配额并稍后重试。
