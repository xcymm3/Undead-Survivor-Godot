# 地图与模式

## 保卫水晶（`graypine_defense`）

项目只提供无尽水晶防守，首页直接选择难度和单人入口；多人暂时关闭，无地图切换。僵尸从断崖对岸的可通行区域连续随机刷新，距桥口至少8米，自然汇向桥口，再依次穿过吊桥、爬上带实心护坡、挡土结构与排水边沟的缓坡，并进入水晶前的开阔高地。对岸平台保留原有的开放地形与光照。地图保留中央长射界，在道路两侧布置可碰撞岩石作为有限掩体；除吊桥两侧的开放断崖外，其他外边界均由连续石墙封闭。草地、土层、道路、岩壁、木桥和石墙使用不同的程序化风化表面。玩家使用固定四格装备：1 步枪、2 左轮、3 消防斧、4 手雷；两把枪的有限弹药整局不补充。水晶正后方的商店取代军械墙，玩家出生在商店区域正中心，仅第一波尚未开始时可用金币制造和升级建筑、升级枪械及手雷容量，用钻石升级天赋。每次清波奖励1颗钻石，金币和成长永久保存。手雷初始1枚、容量最多5枚，每波开始补满。每波结束后停止刷怪，重新按 T 才开始下一波。详见 [增量玩法与存档](INCREMENTAL.md)。

开始前可选择简单、普通或困难。旧基础预算曲线从138分起，第n波新增 max(5, round(31 × 0.92^(n+1))) 分，第20波起基础值每波增加5分，波次无上限。最终预算从第1波的旧值逐波下调，第10波起为旧值的85%；普通单人前十波预算为138、159、178、194、208、220、230、239、246、252分，第20波为320分（旧预算376分）。特殊僵尸积分上限从第1波25%逐波提高，第10波达到50%并保持；剩余积分购买每只0.75分的普通僵尸，尾数小于0.75分时不超额生成。人数倍率仍为1、1.2、1.4、1.6；最终预算在人数倍率后按简单70%、普通100%、困难130%缩放，各步取整。难度不改变敌人属性或橄榄球数量。敌人解锁波次保持不变。橄榄球不占积分：第六、七波各按玩家人数投放，第八波起每波按人数两倍投放，穿插于普通队列。有限弹药武器携带18个弹匣的总弹量，例如步枪30/510；空仓有备弹时自动换弹，R仍可提前换弹。

每波投放分布在开波后的30秒：每批容量为 max(5, ceil(本波总数/30))，批次数为 ceil(总数/容量)，间隔为30/批次数。各批人数按累计比例取整，最后一批在第30秒；数量少时批次间隔变长，超过150只后增加每批数量。出生位置排除桥口8米范围、障碍和无法到达桥的地面；僵尸采用二维移动与软避让，允许彼此重叠，出生仍保留间距策略。暂时无可用位置时保留配额并重试。停止生成爬行僵尸，普通类名额全部生成普通僵尸，旧爬行队列条目也替换为普通。普通单人第一波共150只：138普通、7路障、5铁桶，每秒5只共30批；不是手工固定名单。

普通僵尸持续比较玩家、水晶和存活炮塔的距离，攻击最近的有效目标；小鬼与巨人保留不主动攻击玩家的设定，但可以索敌和攻击炮塔，巨人在水晶旁的范围砸击不会误伤玩家。完整栅栏门挡在路线中时，所有僵尸都必须先攻击门。波次越高，敌人种类和数量越强，但同类敌人属性不随波次放大。水晶拥有固定 1500 点耐久，波间不恢复；水晶被摧毁或全队失去行动能力时失败，清波后进入下一波准备，没有最终波或清波胜利。

平坦高地从82米缩短为54⅔米（原长的2/3），宽度64米及桥、坡尺寸保持不变。水晶位于高地正中心；商店位于靠桥方向的右侧、贴右围墙，玩家出生在商店安全区。

## 每波重置防御建筑与玩家回血

新进度初始没有炮塔和栅栏，左右炮塔分别制造和升级，一枚免费地雷保留。每波正式开始时恢复已购建筑与地雷的状态：炮塔满生命、站立并重置瞄准和射击计时；栅栏恢复升级后的最大耐久并阻挡；地雷清除触发和引信状态。未购建筑不显示也不产生碰撞。

每波正式开始时玩家恢复到天赋提供的最大生命。没有强壮天赋时不缓慢回血；学习后脱战5秒开始按等级回血，攻击、受伤和落水重置计时。每级强壮增加10最大生命和1生命/秒回复速度，最多10级，不能波中复活。枪械弹药在开波和清波时都不补充。

炮塔与栅栏剩余耐久降至50%或以下时显示损伤提示：炮塔持续冒烟，机匣烧黑、护板弯折、侧盖悬垂，内部铜线圈与线缆露出，绿色传感器变红并出现橙色故障灯；栅栏钢条弯折、部分断裂和横梁变形。仍然存活的建筑保留正常火力和阻挡；损伤外观随房主快照同步，下一波重置时恢复完整外壳、绿色指示灯和钢条，并停止冒烟。

| 建筑 | 位置与规则 |
| --- | --- |
| 左右炮塔 | 缓坡左右边缘各一座，200 生命、10 米射程；以距离和视线选择目标，追踪与命中姿态一致的躯干（含爬行僵尸）。基础伤害 60、间隔 0.12 秒，每次建筑升级伤害乘1.1；玩家武器升级和精准天赋不影响炮塔，无爆头加成；持续供弹，无弹匣或换弹。护甲与地形遮挡有效，毁坏后停止射击、倾倒并保留无阻挡残骸。 |
| 地雷 | 水晶前方中央通道，第一只活僵尸进入压力范围后启动，延时直接读取手雷引信，当前 1.5 秒。调用同一个手雷爆炸函数：半径 11 米、伤害由中心 700 向边缘 150 衰减，并保留遮挡、护甲、击退和眩晕规则。不伤害玩家或友方建筑，每波引爆一次。 |
| 栅栏门 | 缓坡顶部，宽 10.4 米、高 1.05 米，1000 基础生命，每次升级最大耐久乘1.1；完整时阻断僵尸通行，玩家可正常跳跃跨过，站立枪线可越过门顶。毁坏时倒下并立即移除阻挡，残骸保留至下一波开始。 |

场景入口为 `scenes/graypine_defense.tscn`，布局与高度见 `scripts/defense_layout.gd`，程序化场景见 `scripts/defense_world.gd`，权威规则位于 `scripts/simulation.gd`。`tools/validate-defense.gd` 无窗口验证地图物理、按 T 开波、商店开启限制、固定装备、最近目标选择、强度成长及胜负条件。

日常 `npm run verify` 运行基础检查；本地图专项可运行 `./tools/validate-headless.ps1 -Mode Defense`、`-Mode DefenseSpawns` 与 `-Mode DefenseStructures`。建筑专项验证火力、遮挡、爬行目标、九种僵尸攻击建筑、玩家越门、地雷与手雷一致、开波重置和快照同步。防守、装备与进度专项覆盖有限弹药、升级、存档、持续射击与受伤后的脱战延迟、每波恢复生命。全量和 Actions 发布门禁也包含建筑专项。自动检查不替代 Steam 双账号联网、原生 GPU 画面或真人体验验收。
