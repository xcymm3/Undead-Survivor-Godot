# 地图与模式

## 保卫水晶（`graypine_defense`）

默认入口为八波水晶防守。僵尸随机从断崖对岸有远近差异的五处位置刷新，自然汇向桥口，再依次穿过吊桥、爬上带实心护坡、挡土结构与排水边沟的缓坡，并进入水晶前的开阔高地。对岸平台保留原有的开放地形与光照。地图保留中央长射界，在道路两侧布置可碰撞岩石作为有限掩体；除吊桥两侧的开放断崖外，其他外边界均由连续石墙封闭。草地、土层、道路、岩壁、木桥和石墙使用不同的程序化风化表面。玩家使用与灰松夜路相同的五格装备栏和有限备弹；副武器、消防斧、手雷及医疗包均可正常使用。水晶后方的军械库墙以四列双行陈列七件主武器，靠近并按 `E` 可替换主武器与补满对应弹药，墙上会立即补回同款武器。军械库还会按玩家人数生成相同数量的手雷和医疗包补给位。每波结束后停止刷怪，所有玩家都重新按 `T` 准备后才开始下一波；不再自动倒计时。

开始前可选择简单、普通或困难。普通难度的八波单人积分预算为 52、83、111、138、162、184、205、223，总计 1158；简单按普通最终预算的 70% 生成普通敌人，困难按 130% 生成。难度只影响普通敌人积分预算，不改变敌人生命、护甲、速度、效果或橄榄球僵尸数量；合作模式以房主开房前选择的难度为准，普通敌人预算继续按人数倍率计算。橄榄球僵尸不占积分：第六、七波各生成与玩家人数相同的数量，第八波生成玩家人数的两倍，并穿插于该波普通敌人之间。仅水晶防线的有限弹药武器携带 18 个弹匣的总弹量（当前弹匣加 17 个备用弹匣，例如步枪为 30/510）；灰松夜路维持当前弹匣加 5 个备用弹匣。两张地图都会在弹匣打空且仍有备弹时自动换弹，`R` 仍可提前换弹。

普通僵尸持续比较玩家和水晶的距离，攻击最近的有效目标；小鬼与巨人则只索敌和攻击水晶，巨人在水晶旁的范围砸击也不会误伤玩家。波次越高，敌人种类和数量越强，但同类敌人属性不随波次放大。水晶拥有固定 1500 点耐久，波间不恢复；水晶被摧毁或全队失去行动能力时失败，清除第八波时胜利。

场景入口为 `scenes/graypine_defense.tscn`，布局与高度见 `scripts/defense_layout.gd`，程序化场景见 `scripts/defense_world.gd`，权威规则位于 `scripts/simulation.gd`。`tools/validate-defense.gd` 无窗口验证地图物理、全员按 T 开波、安全区换装、最近目标选择、强度成长及胜负条件。

## 灰松夜路（`graypine_night`）

原紧凑战役继续保留，可从首页切换。场景入口为 `scenes/graypine_night.tscn`；布局与碰撞见 `scripts/night_layout.gd`、`scripts/night_world.gd`，导演见 `scripts/night_director.gd`。

日常 `npm run verify` 只执行基础检查；修改本地图时可运行 `./tools/validate-headless.ps1 -Mode Defense`。用户明确要求全量验收或准备打包 EXE 时，才由全量流程运行水晶防守专项、夜路整关、ENet、Web 与浏览器检查。水晶防守的多人整关、原生 GPU 和真人节奏仍需单独验收。
