# 地图与模式

## 保卫水晶（`graypine_defense`）

项目只提供无尽水晶防守，首页直接选择难度和单人/合作入口，无地图切换。僵尸随机从断崖对岸有远近差异的五处位置刷新，自然汇向桥口，再依次穿过吊桥、爬上带实心护坡、挡土结构与排水边沟的缓坡，并进入水晶前的开阔高地。对岸平台保留原有的开放地形与光照。地图保留中央长射界，在道路两侧布置可碰撞岩石作为有限掩体；除吊桥两侧的开放断崖外，其他外边界均由连续石墙封闭。草地、土层、道路、岩壁、木桥和石墙使用不同的程序化风化表面。玩家使用五格装备栏和有限备弹；副武器、消防斧、手雷及医疗包均可正常使用。水晶后方的军械库墙以四列双行陈列七件主武器，靠近并按 `E` 可替换主武器与补满对应弹药，墙上会立即补回同款武器。军械库还会按玩家人数生成相同数量的手雷和医疗包补给位。每波结束后停止刷怪，所有玩家都重新按 `T` 准备后才开始下一波；不再自动倒计时。

开始前可选择简单、普通或困难。普通单人预算由公式生成：第1波52分，第n波新增 max(5, round(31 × 0.92^(n−2))) 分；前八波为 52、83、112、138、162、184、204、223，总计仍为1158。第23波起每波固定增加5分，波次无上限；简单按普通最终预算的 70% 生成普通敌人，困难按 130% 生成。难度只影响普通敌人积分预算，不改变敌人生命、护甲、速度、效果或橄榄球僵尸数量；合作模式以房主开房前选择的难度为准，普通敌人预算继续按人数倍率计算。橄榄球僵尸不占积分：第六、七波各生成与玩家人数相同的数量，第八波及之后每波生成玩家人数的两倍，并穿插于该波普通敌人之间。有限弹药武器携带 18 个弹匣的总弹量（当前弹匣加 17 个备用弹匣，例如步枪为 30/510）。在弹匣打空且仍有备弹时自动换弹，`R` 仍可提前换弹。

普通僵尸持续比较玩家、水晶和存活炮塔的距离，攻击最近的有效目标；小鬼与巨人保留不主动攻击玩家的设定，但可以索敌和攻击炮塔，巨人在水晶旁的范围砸击不会误伤玩家。完整栅栏门挡在路线中时，所有僵尸都必须先攻击门。波次越高，敌人种类和数量越强，但同类敌人属性不随波次放大。水晶拥有固定 1500 点耐久，波间不恢复；水晶被摧毁或全队失去行动能力时失败，清波后进入下一波准备，没有最终波或清波胜利。

## 一次性防御建筑

每局地图固定布置两座炮塔、一枚地雷和一扇栅栏门。建筑状态由单人或合作房主计算，并随世界快照同步给客户端；开始下一波、重新准备和补给都不会恢复建筑，只有新开一局才重置。

| 建筑 | 位置与规则 |
| --- | --- |
| 左右炮塔 | 缓坡左右边缘各一座，200 生命、10 米射程；以距离和视线选择目标，追踪与命中姿态一致的躯干（含爬行僵尸）。每发伤害和射击间隔直接读取步枪，当前为 120 / 0.12 秒，无爆头加成；持续供弹，无弹匣或换弹。护甲与地形遮挡有效，毁坏后停止射击、倾倒并保留无阻挡残骸。 |
| 地雷 | 水晶前方中央通道，第一只活僵尸进入压力范围后启动，延时直接读取手雷引信，当前 1.5 秒。调用同一个手雷爆炸函数：半径 11 米、伤害由中心 700 向边缘 150 衰减，并保留遮挡、护甲、击退和眩晕规则。不伤害玩家或友方建筑，仅引爆一次。 |
| 栅栏门 | 吊桥靠近缓坡一侧，宽 7.65 米、高 1.05 米，1000 生命；完整时阻断僵尸通行，玩家可正常跳跃跨过，站立枪线可越过门顶。毁坏时倒下并立即移除阻挡，门板残骸保留，不再恢复。 |

场景入口为 `scenes/graypine_defense.tscn`，布局与高度见 `scripts/defense_layout.gd`，程序化场景见 `scripts/defense_world.gd`，权威规则位于 `scripts/simulation.gd`。`tools/validate-defense.gd` 无窗口验证地图物理、全员按 T 开波、安全区换装、最近目标选择、强度成长及胜负条件。

日常 `npm run verify` 运行基础检查；本地图专项可运行 `./tools/validate-headless.ps1 -Mode Defense`、`-Mode DefenseSpawns` 与 `-Mode DefenseStructures`。建筑专项验证火力、遮挡、爬行目标、九种僵尸攻击建筑、玩家越门、地雷与手雷一致、跨波持久状态和快照同步。全量和 Actions 发布门禁也包含建筑专项。自动检查不替代 Steam 双账号联网、原生 GPU 画面或真人体验验收。
