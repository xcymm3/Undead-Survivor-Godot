# 地图与模式

## 保卫水晶（`graypine_defense`）

项目只提供无尽水晶防守，首页直接选择难度和单人/合作入口，无地图切换。僵尸从断崖对岸的可通行区域连续随机刷新，距桥口至少8米，自然汇向桥口，再依次穿过吊桥、爬上带实心护坡、挡土结构与排水边沟的缓坡，并进入水晶前的开阔高地。对岸平台保留原有的开放地形与光照。地图保留中央长射界，在道路两侧布置可碰撞岩石作为有限掩体；除吊桥两侧的开放断崖外，其他外边界均由连续石墙封闭。草地、土层、道路、岩壁、木桥和石墙使用不同的程序化风化表面。玩家使用四格装备栏：1 武器1、2 武器2、3 固定消防斧、4 手雷。默认携带步枪和自动霰弹枪，两个武器槽不再区分主副武器，弹仓与备弹独立保存，同款枪也不共享弹药。军械墙单行提供步枪、自动霰弹枪、喷火枪、狙击枪；按 1 或 2 选择要替换的槽，再靠近按 E 换枪并补满该槽弹药。选中斧或手雷时领取默认替换武器1。移除医疗包、治疗操作和所有物品补给位。手雷在每波实际开始时自动补满至3枚，准备阶段不补充，合作模式须全员准备后才补充。每波结束后停止刷怪，所有玩家都重新按 `T` 准备后才开始下一波；不再自动倒计时。

开始前可选择简单、普通或困难。普通单人预算曲线前移三波：第1波138分，第n波新增 max(5, round(31 × 0.92^(n+1))) 分；前八波为 138、162、184、204、223、240、256、271。第20波起每波固定增加5分，波次无上限；简单按普通最终预算的70%生成，困难按130%生成。普通每只0.75分，特殊僵尸最多使用总预算25%，剩余积分购买普通僵尸；未满一只的尾数小于0.75分，不超额生成。难度只影响积分预算，不改变敌人属性或橄榄球数量；人数倍率仍为1、1.2、1.4、1.6。敌人解锁波次保持不变。橄榄球不占积分：第六、七波各按玩家人数投放，第八波起每波按人数两倍投放，穿插于普通队列。有限弹药武器携带18个弹匣的总弹量，例如步枪30/510；空仓有备弹时自动换弹，R仍可提前换弹。

每波投放分布在开波后的30秒：每批容量为 max(5, ceil(本波总数/30))，批次数为 ceil(总数/容量)，间隔为30/批次数。各批人数按累计比例取整，最后一批在第30秒；数量少时批次间隔变长，超过150只后增加每批数量。出生位置排除桥口8米范围、障碍和无法到达桥的地面；僵尸采用二维移动与软避让，允许彼此重叠，出生仍保留间距策略。暂时无可用位置时保留配额并重试。停止生成爬行僵尸，普通类名额全部生成普通僵尸，旧爬行队列条目也替换为普通。普通单人第一波共150只：138普通、7路障、5铁桶，每秒5只共30批；不是手工固定名单。

普通僵尸持续比较玩家、水晶和存活炮塔的距离，攻击最近的有效目标；小鬼与巨人保留不主动攻击玩家的设定，但可以索敌和攻击炮塔，巨人在水晶旁的范围砸击不会误伤玩家。完整栅栏门挡在路线中时，所有僵尸都必须先攻击门。波次越高，敌人种类和数量越强，但同类敌人属性不随波次放大。水晶拥有固定 1500 点耐久，波间不恢复；水晶被摧毁或全队失去行动能力时失败，清波后进入下一波准备，没有最终波或清波胜利。

平坦高地从82米缩短为54⅔米（原长的2/3），宽度64米及桥、坡尺寸保持不变。水晶位于高地正中心；军械库移到靠桥方向的右侧，武器墙贴右围墙并朝场内，玩家出生在军械库安全区。

## 每波重置防御建筑与玩家回血

地图固定布置两座炮塔、一枚地雷和一扇栅栏门。每波正式开始时恢复全部初始状态：炮塔满生命、站立并重置瞄准和射击计时；栅栏门满耐久并恢复阻挡；地雷重新布置、清除触发和引信状态。进入准备阶段、部分玩家准备和领取补给不触发重置。建筑状态由单人或合作房主计算，并随世界快照同步给客户端。

每波正式开始时所有玩家恢复到100生命。存活玩家持续每秒恢复1点生命，开枪、受伤和落水不暂停回血，准备阶段也可回血；上限100，波中回血不会复活死亡玩家。合作模式须全员准备后才触发开波回血与建筑重置。

炮塔与栅栏剩余耐久降至50%或以下时显示损伤提示：炮塔持续冒烟，机匣烧黑、护板弯折、侧盖悬垂，内部铜线圈与线缆露出，绿色传感器变红并出现橙色故障灯；栅栏钢条弯折、部分断裂和横梁变形。仍然存活的建筑保留正常火力和阻挡；损伤外观随房主快照同步，下一波重置时恢复完整外壳、绿色指示灯和钢条，并停止冒烟。

| 建筑 | 位置与规则 |
| --- | --- |
| 左右炮塔 | 缓坡左右边缘各一座，200 生命、10 米射程；以距离和视线选择目标，追踪与命中姿态一致的躯干（含爬行僵尸）。每发伤害为步枪的一半，射击间隔直接读取步枪，当前为 60 / 0.12 秒（理想 DPS 500），无爆头加成；持续供弹，无弹匣或换弹。护甲与地形遮挡有效，毁坏后停止射击、倾倒并保留无阻挡残骸。 |
| 地雷 | 水晶前方中央通道，第一只活僵尸进入压力范围后启动，延时直接读取手雷引信，当前 1.5 秒。调用同一个手雷爆炸函数：半径 11 米、伤害由中心 700 向边缘 150 衰减，并保留遮挡、护甲、击退和眩晕规则。不伤害玩家或友方建筑，每波引爆一次。 |
| 栅栏门 | 缓坡顶部，宽 10.4 米、高 1.05 米，1000 生命；完整时阻断僵尸通行，玩家可正常跳跃跨过，站立枪线可越过门顶。毁坏时倒下并立即移除阻挡，残骸保留至下一波开始。 |

场景入口为 `scenes/graypine_defense.tscn`，布局与高度见 `scripts/defense_layout.gd`，程序化场景见 `scripts/defense_world.gd`，权威规则位于 `scripts/simulation.gd`。`tools/validate-defense.gd` 无窗口验证地图物理、全员按 T 开波、安全区换装、最近目标选择、强度成长及胜负条件。

日常 `npm run verify` 运行基础检查；本地图专项可运行 `./tools/validate-headless.ps1 -Mode Defense`、`-Mode DefenseSpawns` 与 `-Mode DefenseStructures`。建筑专项验证火力、遮挡、爬行目标、九种僵尸攻击建筑、玩家越门、地雷与手雷一致、开波重置和快照同步。防守与装备专项覆盖持续射击、受伤后的回血和合作全员准备时恢复生命。全量和 Actions 发布门禁也包含建筑专项。自动检查不替代 Steam 双账号联网、原生 GPU 画面或真人体验验收。
