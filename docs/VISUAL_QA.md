# 视觉质量验收

本机只使用真正 headless Godot 和独立 headless Chromium。原生 GPU 取图需另行获授权的隔离环境；禁止使用 capture-hidden.ps1、隐藏父窗口、离屏 SubViewport 或先启动再隐藏的桌面取图方案。

功能通过、截图存在和非空白检测均不能替代逐图视觉审查。打开原尺寸截图，检查目标提示、门和道具标识、河岸接缝、桥与闸门、可选院落入口、战斗与队友遮挡、结算布局。至少包含 960×540、1440×900、1920×1080 的 HUD 检查。

灰松渡口的软件 Web 视点见 tests/browser/campaign.spec.mjs。固定视点为取图场景，另有真实按键出发与内部输入整关遍历，不混称同一验证。实际审查发现、修复与复查证据写入 artifacts/visual-review.md。

原生 GPU、连续运动手感、不同显卡和超宽屏、Steam 双账号完整画面未覆盖时明确记录为待验收；不能因为软件 Web 和功能通过而标记为原生视觉通过。
