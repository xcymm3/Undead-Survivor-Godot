# 按需视觉检查

视觉检查不属于日常基础测试。只有用户明确要求截图、视觉验收、画面复查或全量验收包含视觉项目时才执行。

## 规则

1. 本机只使用真正 headless 的 Godot 与独立 headless Chromium，不启动或隐藏可见图形窗口。
2. 截图生成后必须打开原尺寸图片检查；文件非空和自动断言通过不能代替人工观察。
3. 地图检查空间顺序、坡度、高差、碰撞接缝和关键目标可读性；UI 检查裁切、重叠、字号与状态反馈；角色和武器检查穿插、姿态、枪口和动作阶段。
4. 在 `artifacts/visual-review.md` 记录源码摘要、渲染环境、截图路径、发现和复查结果。源码或美术再次改变后，旧结论不再代表当前版本。
5. 软件 Web 截图不能冒充原生 GPU、连续动态或真人手感验收；未覆盖项应明确列出。

当前保留的专用地图截图测试是 `tests/browser/defense-overview.spec.mjs`，用于生成“保卫水晶”斜俯视全图。其他视觉需求按用户提出的具体范围临时补充，不长期保留大规模截图矩阵。
