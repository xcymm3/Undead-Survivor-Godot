# 原创玩家角色

四个玩家角色由 `scripts/survivor_model.gd` 原生构建，不使用下载的人物网格。采用与僵尸一致的方块结构，补充人类肤色、眼睛、鼻子、耳朵、头发、服装与分节四肢：

| 编号 | 角色 | 性别 | 识别特征 |
| --- | --- | --- | --- |
| 0 | 蓝衣青年 | 男 | 短发、蓝衣 |
| 1 | 棕衣大叔 | 男 | 胡须、较宽肩膀、棕衣 |
| 2 | 绿衣队员 | 男 | 浅肤色、绿衣、战术背心 |
| 3 | 红衣女性 | 女 | 披肩长发、较窄肩膀、红衣 |

模型朝向 -Z，使用游戏单位构建。骨骼绑定采用刚性分节结构，便于继续调整尺寸和配色。腿部具有程序化行走、跳跃姿态，手臂根据握持目标求解，消防斧手部跟随挥砍。当前没有面部表情、布料模拟或逐指动画。

房主或单人模拟器在玩家加入时从尚未使用的角色中随机选择；四人队伍不重复。角色编号通过既有 appearance 快照同步，加入新玩家不会改变其他人的模型。离开后空出的角色可被新玩家使用；重开游戏重新分配。保留 appearance 三元素协议结构，颜色字段固定为 0，服装使用四套固定设计。

HUD 头像复用相同的三维模型。角色变化不改变生命值、移动速度、射击和近战伤害。

日常 `npm run verify` 只覆盖原生组件基础断言。角色联网和浏览器输入只在用户明确要求全量验收或打包 EXE 时执行；角色外观截图按用户提出的视觉范围临时生成，不再保留大规模固定截图矩阵。
