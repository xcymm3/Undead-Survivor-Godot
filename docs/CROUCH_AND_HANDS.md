# 蹲下与双手持枪

- 按住 Ctrl 蹲下，松开站起。蹲行速度为站立的 55%；头顶空间不足时保持蹲下，离开障碍后站起。
- 单人与合作房主使用相同的原生胶囊碰撞体和姿态计算。客户端发送蹲下意图，接收房主确认后的姿态；远端角色弯曲双腿，身体、持枪位置及昵称随之降低。
- 蹲下同步降低相机、子弹及近战判定的起点。蹲下时不能直接跳跃，站起后恢复跳跃。
- 按用户最新要求，第一人称只显示武器，不创建或显示玩家手臂；腰射、举枪、换弹和近战均沿用武器自身动作。第三人称角色与治疗动作保留。
- 步枪使用原创原生 AK47 风格程序网格：木质护木/枪托、黑色机匣、弯弹匣、机械瞄具和拉机柄。第一、第三人称共用模型，原伤害、弹量和射速不变。

## 验证边界

完整功能验证使用 `npm run verify`。原生检查覆盖低顶棚下禁止站起、速度与胶囊高度；两张地图分别运行 ENet 双人/四人蹲下与站起同步。实际浏览器按键检查 Ctrl。

`tests/browser/poses.spec.mjs` 使用专用 `?poses=1` QA 入口，在真正无界面的 Chromium 中用 SwiftShader 渲染原生 Godot 网格。为避免桌面干扰和软件渲染过载，姿态矩阵使用低帧率的简易展示场景；不冒充实际联网游玩或原生 GPU 验收。该入口只在 `--automation --qa-poses` 的 Web 导出中启用，不进入正常 EXE 流程。

视觉审查包含十种武器腰射/举枪、AK 换弹阶段与射击、第一人称蹲下、远端站立/蹲下的正面和侧面。逐图审查记录保存在 `artifacts/crouch-arms-review/`。原生 GPU 的 `docs/VISUAL_QA.md` 全矩阵仍需符合桌面隔离要求的环境，不在用户桌面运行任何图形 Godot 进程。
