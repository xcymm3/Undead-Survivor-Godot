# 单人增量玩法（2026-10-12）

现行规则替代旧军械库换枪、无限手枪备弹和无条件自动回血。暂时关闭多人入口和普通运行中的 Steam/ENet 建房、加入功能；旧网络组件保留为后续开发资源。

## 对局和永久进度

按住 Shift 疾跑，基础移速由 4.2 提升至 6.72 米/秒，并与迅捷天赋相乘；无耐力限制。射击、开镜、换弹、蹲下和推搡取消疾跑，步枪与手枪采用压低枪口、横持及跑动摆动动作。跳跃保留起跳时的疾跑惯性。

固定装备为 1 步枪、2 手枪、3 消防斧、4 手雷。两把枪均使用有限备弹，初始为步枪 30/510、手枪 15/255；开波不补弹，每次清波步枪增加 60 发、手枪增加 30 发备弹，可以超过原备弹上限，当前弹匣不变。重新开始一局才按补给天赋恢复弹匣和备弹。

新进度初始 0 金币、0 钻石，无炮塔、栅栏门和地雷。商店位于水晶正后方，玩家出生在商店区域正中心，朝向水晶。整备区有步枪、手枪、消防斧、手雷及四种天赋共八个实体展台。靠近并瞄准目标时才显示无边框等级、属性和价格，长按 E 3 秒完成一次购买，E 周围的圆环逐渐填满，付款钱币从玩家飞向目标；转开、走远、遮挡或松开均取消进度，完成后必须松开才能再次购买，整备不暂停模拟。建筑与地雷在原位置的工具箱施工点分别建造，已建造炮塔与栅栏在现场升级。仅重新开始后、第一波尚未启动时允许购买；在独立警报器上长按 E 后，本局商店一直关闭，清波也不重新开放。

金币、钻石、武器升级、手雷容量、建筑所有权和建筑等级、天赋、最佳波次和累计清波数永久保留。死亡或退出不撤回已获得奖励。重开仅重置波次、生命、弹药和战场状态。每次实际清除一波奖励 1 钻石，重复重开后清除同一波也能再次获得；同一局重复处理相同波次不重复奖励，失败不奖励。

## 十波连续进攻

准备阶段在独立警报器上长按 E 启动第一波。各波仍按30秒动态批次投放；投放队列为空后等待10秒，再自动启动下一波，不要求场上的旧敌人已经死亡。出生点被阻挡时保留队列，因此不会提前跳波。每个敌人保存所属波次，全部清除该波才结算钻石和两把枪的备弹夹，奖励不会重复。第十波停止接波；击败舞王即清除全部残余敌人、按正常击杀发放金币并通关。

舞王在第十波出现一只，生命为橄榄球的10倍（90000）、移速为普通僵尸随机速度的一半（2.3～2.6米/秒）。每10秒开始一次3秒跳舞与原创迪斯科音效，跳舞期间不移动、攻击；随后按普通25、特殊25积分组成队列，余数不足一只时不超预算。每帧最多释放8只，在附近可通行且直接连通的地面出现，用共享CPU/GPU姿态播放1.4秒钻地动作；舞王死亡后停止产生新的召唤。

## 钻石天赋

四种天赋分别最多 10 级。购买第 n 级消耗 n 颗钻石，从 1、2、3 到 10；一种天赋升满累计 55 钻石。

| 天赋 | 每级效果 | 满级 |
| --- | --- | --- |
| 强壮 | +10 最大生命，脱战 5 秒后 +1 生命/秒回复速度 | 200 最大生命、10 生命/秒 |
| 精准 | 现有爆头倍率增加基础倍率的 20% | 基础爆头倍率 ×3 |
| 迅捷 | 基础移速 +5% | 基础移速 ×1.5 |
| 补给 | 开局备弹 +20% | 步枪 1530、手枪 765 备弹 |

无强壮天赋时没有持续自动回血。连续五秒未受到有效伤害后开始回血；射击、斧击、投雷和推击均不打断计时或回血。受到有效伤害或落水扣血会重新计时并清除未结算的回血量。回血不能超过已升级的生命上限，也不能复活。升级补给仅增加新容量与旧容量的差额，不补回整备时已经消耗的弹药。

## 存档与验证

首页可选择三个独立存档，选择后重新开始第一波准备；每个新存档从0金币、0钻石、无升级和建筑开始。存档1沿用 `user://incremental-progress-v1.json` 并保留旧进度，存档2、3分别使用 `user://incremental-progress-slot-2.json`、`user://incremental-progress-slot-3.json`，`user://incremental-slots.json` 记住当前选择。三个文件独立于设置/成绩文件。首页“无限金币”勾选框用于测试，进入对局将所选存档金币设为10亿，取消勾选不会清空已存金币。使用临时文件写入并替换，保留上一份有效 `.bak`；主文件损坏时恢复备份并显示提示。购买保存失败会回退扣款和等级变化；击杀收益每秒批量落盘，对局结束、重开、返回主页和正常退出立即保存。没有恢复中途战斗的功能。

存档内容升级为版本 2，沿用原文件路径。读取旧版本时保留所有原进度和原免费地雷的所有权，新增桥尾栅栏及两枚新地雷仍需购买；有效旧备份也支持迁移。新进度三枚地雷均需购买，购买后没有升级或重复购买选项。

自动化使用独立内存进度，不读取或改写玩家存档。`npm run verify` 新增进度/存档专项；也可运行 `tools/validate-headless.ps1 -Mode Progression`。专项覆盖价格递增、上限、存档重读及损坏恢复、保存失败回退、奖励去重、金币飞行、实际炮塔升级伤害、原生商店按钮和关闭限制、脱战回血、弹药保留、重开永久进度等。十波战役专项覆盖连续投放、按所属波次清波奖励、三档隔离、就地升级、夜间参数、舞王召唤与钻地动作、最终胜利。防线和建筑专项覆盖原生移动、碰撞、索敌、射击及不复活的建筑状态。

本次执行无窗口基础及相关专项；没有执行全量、浏览器、视觉或 EXE 发布验收，也不把自动规则检查称为真人平衡测试。

## 场景内整备与奖励表现

开始防守后直接控制玩家，不弹准备菜单。开战时八个展台收起商品、关闭工作灯并盖上金属防护罩，警报器变红；暂停菜单没有开战按钮，T 不再启动进攻。水晶、商店及波次的常驻悬浮牌全部移除，场景只保留一条靠近且瞄准目标时出现的无边框说明。炮塔、栅栏与展台长按交互有工作工具、光效与完成反馈；不改变既有价格、成长、战斗恢复或永久存档规则。金币采用粗糙八边形厚币、大块平面明暗与简化符号，钻石采用带深色轮廓的粗切面图标，共享纹理与批量网格；右上角钱包使用钱币、切面钻石图标与数字。

视觉截图由 GitHub Actions 隔离运行无界面 Chromium + SwiftShader 的 Godot Web 导出生成，包含战前全景、关闭全景、展台信息和金币钱包特写。该环境不访问用户桌面，也不代表原生 GPU 或真人手感验收。

每次新波次启动会显示无边框播报，0.45秒淡入、保持至2.35秒、0.65秒淡出，总计3秒；最终波显示“第10波-最后一波！”。接波间隔使用模拟时钟，暂停时不计时，残余敌人在间隔内继续战斗，商店保持关闭。第十波不再安排间隔或第十一波。

水晶使用分层低多边形切面、细能量环与三枚环绕晶片，36秒缓慢旋转一圈并轻微浮动；动画只影响视觉根节点，碰撞、导航、目标耐久与攻击接触范围不随旋转改变。步枪、手枪与消防斧展台围绕展示中心40秒旋转一圈，台面与交互位置固定，开战后仍收起商品。


## 战斗反馈与战场收尾

开战后关闭所有世界说明文字（含商店、展台、建筑、水晶），HUD 操作说明仅显示当前可用操作，移除武器基础档位字母。强壮天赋实际恢复生命时出现轻微绿色屏幕边缘与低音量短音，音效最多每3秒一次，不对满血或受伤等待阶段提示。各武器使用独立的机械换弹音序列，斧不产生换弹事件。

水晶在耐久不高于50%且尚未破碎时显示裂纹与能量闪动；归零时核心消失，18个碎片向外飞散并落地，固定碰撞关闭。舞王登场后 HUD 顶部显示名称、血条和具体生命值；击败舞王立即清除所有残敌，并发放其正常击杀奖励，随后进入战场收尾。

失败时先用1.8秒转入倒下玩家或破碎水晶的镜头，结算面板在3.8秒后出现；胜利也保留战场收尾。结算显示本局金币和钻石获取总量，并说明永久保存的升级与所有权。主页采用中心标题、原生动态背景与底部操作区；暂停、设置、存档、指南、结算面板共用深色金属与黄铜边框风格。按需截图由云端 headless Chromium / SwiftShader 生成，不能代替原生 GPU 动态体验和音效试听。

2026-10-13：普通手枪基础伤害100、弹匣15发，旧左轮升级永久迁移到手枪。消防斧可右键推搡并前推斧柄。舞王在第10波开始立即出现，速度与普通僵尸相同。普通敌人仅在15米内、玩家比建筑更近且可达时追击玩家；小鬼与巨人仍优先建筑。主页移除难度选择，固定普通难度，标题采用带石材颗粒与缺口的立体字。脱战回血增强绿色屏幕提示。

水晶生命上限3000，受击播放清脆晶体碰撞声。已建造栅栏整块门体均可瞄准长按升级，范围3.2米并保留遮挡检查。消防斧按住左键可连续挥砍。付款金额≤100、101–1000、>1000的飞币间隔分别为0.18、0.09、0.045秒；长按期间购买音渐强，中断即停止，掉落钱币抵达玩家时逐枚播放拾币提示。

步枪单发最多命中沿弹道的3只僵尸，按距离由近到远结算；每穿过一只，后续伤害乘2/3，基础躯干伤害为120、80、约53.33。护甲吸收、爆头及永久升级照常结算，墙体仍阻挡子弹，第4只不受伤。


## 2026-10-14 一秒整备与十级升级上限

世界交互长按E满1秒完成，购买声持续1秒并随进度增加音量、音高；取消、暂停或完成后停止。新增两个实体弹匣展台，步枪与手枪容量各自永久升级，首次20金币、后续翻倍，每级乘1.2、上限10级。基础30/15发，第1级36/18发，第10级186/93发。购买只增加容量，不凭空补入弹药；换弹从有限备弹装入升级后的容量，重开补满新弹匣，清波奖励也按升级后两弹匣计算。补给天赋仍只增加基础备弹的比例。

武器伤害、炮塔伤害、栅栏耐久由每级乘1.1改为乘1.2，最多购买10次；精准与补给改为每级增加20个百分点，仍最多10级。强壮的每级+10生命、+1回复以及迅捷的每级+5%移速保持原值；手雷仍最多5颗、地雷无升级。所有已满级升级显示LV MAX并禁止扣款。存档升至版本4，原版本1～3继续迁移，新增弹匣等级初始0，旧武器或建筑超过10级时归到新上限10；保留金币、钻石和建筑所有权。

验证使用无窗口基础与防线专项，覆盖一秒阈值、取消与锁存、渐强音量、独立弹匣购买与保存、有限备弹换弹、清波奖励、10级后拒绝扣款、旧存档迁移。未执行视觉验收、音效试听、全量或EXE发布。
