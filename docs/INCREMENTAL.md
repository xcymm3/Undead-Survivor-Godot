# 单人增量玩法（2026-09-30）

现行规则替代旧军械库换枪、无限左轮备弹和无条件自动回血。暂时关闭多人入口和普通运行中的 Steam/ENet 建房、加入功能；旧网络组件保留为后续开发资源。

## 对局和永久进度

按住 Shift 疾跑，基础移速由 4.2 提升至 6.72 米/秒，并与迅捷天赋相乘；无耐力限制。射击、开镜、换弹、蹲下和推搡取消疾跑，步枪与左轮采用压低枪口、横持及跑动摆动动作。跳跃保留起跳时的疾跑惯性。

固定装备为 1 步枪、2 左轮、3 消防斧、4 手雷。两把枪均使用有限备弹，初始为步枪 30/510、左轮 6/102；整局包括第一波开始、清波和波间准备都不补充弹药。重新开始一局才按补给天赋恢复弹匣和备弹。

新进度初始 0 金币、0 钻石，无炮塔和栅栏门；一枚免费地雷仍然每波重置。商店位于水晶正后方，玩家出生在商店区域正中心，朝向水晶。原军械库改成商店柜台，靠近按 E 打开，整备时暂停单人模拟。仅重新开始后、第一波尚未启动时允许购买；第一次按 T 开波后，本局商店一直关闭，清波也不重新开放。

金币、钻石、武器升级、手雷容量、建筑所有权和建筑等级、天赋、最佳波次和累计清波数永久保留。死亡或退出不撤回已获得奖励。重开仅重置波次、生命、弹药和战场状态。每次实际清除一波奖励 1 钻石，重复重开后清除同一波也能再次获得；同一局重复处理相同波次不重复奖励，失败不奖励。

## 金币和装备

| 原始敌人类型 | 金币 |
| --- | ---: |
| 普通 | 1 |
| 路障 | 2 |
| 铁桶、小鬼 | 3 |
| 盾牌 | 5 |
| 狂暴者、巨人 | 10 |
| 橄榄球 | 20 |

护甲破坏后仍按原始种类结算。枪、斧、手雷、地雷和炮塔击杀均计入单人的永久金币。金币使用共享 MultiMesh 表现自动飞向玩家，不创建物理实体；最多显示 512 个掉落。击杀时即记账，飞行动画不再结算，避免重复领取或退出时丢失在途奖励。

| 项目 | 首次价格 | 效果 |
| --- | ---: | --- |
| 步枪 / 左轮 / 消防斧伤害 | 各 20 金币 | 每次在当前伤害上乘 1.1，下一次价格翻倍 |
| 手雷容量 | 30 金币 | 初始 1，上限 5，每次 +1，下一次价格翻倍 |
| 左炮塔 / 右炮塔制造 | 各 100 金币 | 分别拥有、分别升级 |
| 炮塔伤害升级 | 各 50 金币 | 每次伤害乘 1.1，下一次价格翻倍 |
| 栅栏制造 | 80 金币 | 获得 1000 基础耐久栅栏 |
| 栅栏耐久升级 | 40 金币 | 每次最大耐久乘 1.1 后取整，下一次价格翻倍 |

炮塔基础伤害 60、耐久 200、间隔 0.12 秒；枪械升级和精准天赋不影响炮塔。每波实际开始时，已购炮塔、栅栏和免费地雷恢复初始状态及完整外观；未购建筑不显示、不阻挡。每波开始回满玩家的当前最大生命，并补满已升级的手雷容量；不补枪械弹药，不修复水晶。

## 钻石天赋

四种天赋分别最多 10 级。购买第 n 级消耗 n 颗钻石，从 1、2、3 到 10；一种天赋升满累计 55 钻石。

| 天赋 | 每级效果 | 满级 |
| --- | --- | --- |
| 强壮 | +10 最大生命，脱战 5 秒后 +1 生命/秒回复速度 | 200 最大生命、10 生命/秒 |
| 精准 | 现有爆头倍率增加基础倍率的 10% | 基础爆头倍率 ×2 |
| 迅捷 | 基础移速 +5% | 基础移速 ×1.5 |
| 补给 | 开局备弹 +10% | 步枪 1020、左轮 204 备弹 |

无强壮天赋时没有持续自动回血。攻击（射击、斧击、投雷、推击）、受到有效伤害和落水都重置五秒脱战计时，回血不能超过已升级的生命上限，也不能复活。升级补给仅增加新容量与旧容量的差额，不补回整备时已经消耗的弹药。

## 存档与验证

永久进度文件为 Godot 用户目录中的 `user://incremental-progress-v1.json`，独立于旧设置/成绩文件。使用临时文件写入并替换，保留上一份有效 `.bak`；主文件损坏时恢复备份并显示提示。购买保存失败会回退扣款和等级变化；击杀收益每秒批量落盘，对局结束、重开、返回主页和正常退出立即保存。没有恢复中途战斗的功能。

自动化使用独立内存进度，不读取或改写玩家存档。`npm run verify` 新增进度/存档专项；也可运行 `tools/validate-headless.ps1 -Mode Progression`。专项覆盖价格递增、上限、存档重读及损坏恢复、保存失败回退、奖励去重、金币飞行、实际炮塔升级伤害、原生商店按钮和关闭限制、脱战回血、弹药保留、重开永久进度等。防线和建筑专项继续覆盖原生移动、碰撞、索敌、射击与每波重置。

本次执行无窗口基础及相关专项；没有执行全量、浏览器、视觉或 EXE 发布验收，也不把自动规则检查称为真人平衡测试。
