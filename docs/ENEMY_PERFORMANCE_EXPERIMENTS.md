# 独立尸潮 CPU 实验

正式玩法代码保持原样。`tools/enemy-experiment-variants.mjs` 只修改每次新建的临时冻结工程，四个版本为原版、导航实验、射线实验、动画实验。后三者均从同一原版复制，互不叠加。源码清单和实验文件哈希随采样保存。

```powershell
node tools/run-enemy-experiments.mjs --diagnostics
node tools/summarize-enemy-experiments.mjs
```

所有 Godot 进程固定使用 `--headless --audio-driver Dummy`，禁止使用本工具启动桌面画面。实验串行运行；顺序为原版、导航、射线、动画、动画、射线、导航、原版。第二轮反转敌人数和场景顺序。50/100/200/300 只普通敌人，各测移动、桥口拥堵、步枪和自动霰弹枪持续射击；预热60帧、采样180帧，每项两轮。额外分段诊断仅测300只，有探针，不能替代无探针的性能对照。

导航原型缓存按精确目标格、建筑状态失效的路径后缀树，玩家追踪保留原寻路；12米外索敌缓存0.1～0.2秒，目标死亡或建筑状态改变立即失效；每个邻居桶轮换抽样最多4只，每次移动最多检查32只，拥挤桶降低分离强度，仍允许重叠。候选经过原距离限制，未改护栏与障碍检查。本原型是共享路径缓存，并非覆盖整张地图的完整方向场。

射线原型在一次射击和一次准星更新各建立独立空间网格，沿射线取候选，保持原序和部件精确检测。姿态按精确时间、完整敌人状态与stationary参数缓存，状态变化立即重新计算，不用显示姿态代替权威姿态。该原型仍需每次建立网格，未复用模拟移动的桶；准星热路径在测量脚本中替换，其余生产界面不变。

动画原型缓存模型选择，近处15米内60Hz、中距离40米内30Hz、远处15Hz；按61度视野、16:9比例和体型余量筛选屏外骨骼提交。根节点继续更新，命中计算不降频。**低频骨骼暂保持上一采样，没有新增GPU插值；这是CPU提交原型，不能视为已完成视觉验收或可以直接上线。** 正式采用前还需要实现合适的过渡、验证可见姿态与射击反馈，并在真实GPU环境验收。

数据保存于 `artifacts/enemy-experiments/`。汇总包含均值、P50、P95、P99、最大值、16.67ms超预算比例、预热帧、敌人激活耗时、移动比例、命中和射击数量。CPU段合计为模拟+动画计算/提交+准星检测，不是实际FPS；模拟内部子项不可再次相加，物理监视器是非加性的上下文指标。死亡、动态补怪、精英混合和舞王召唤尚不在性能样本中，混合种类射线由独立正确性测试覆盖。

第一轮每个版本运行导航96项、原生组件988项及5种武器弹道检查；射线额外检查600条随机混合种类射线与原精确检测的一致性，动画额外检查9项LOD行为。失败或冻结源码摘要不一致时拒绝汇总。

GitHub Actions 从 `automation.yml` 的 `enemy_profile_only=true` 入口运行隔离 Windows CPU 测量，保存采样和源文件摘要，不导出或发布EXE。不同机器的绝对毫秒数不能直接对比，只比较同一环境内的独立版本。用户已确认暂时没有隔离GPU机器，GPU帧时间、阴影、夜景光照、透明效果和模型LOD测量暂缓。
